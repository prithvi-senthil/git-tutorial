Installation & Configuration

Before writing code, tell Git who you are so your commits are properly attributed.

Set your global username:
git config --global user.name "Your Name"
Set your global email:
git config --global user.email "your.email@example.com"
Verify your configuration:
git config --list
2

The Core Workflow (Init, Add, Commit)

Understand the three states of Git: Modified (working directory), Staged (staging area), and Committed (repository history).

Initialize a new repository in your folder:
git init
Check current repository status:
git status
Stage files for commit (or use git add . for all):
git add filename.html
Commit staged changes with a descriptive message:
git commit -m "feat: add homepage hero layout"
3

Branching & Merging

Work on features safely without disrupting your main production code using branches.

Create and switch to a new feature branch simultaneously:
git checkout -b feature-login
List all local branches:
git branch
Merge your branch back into main (first switch to main):
git checkout main && git merge feature-login
4

Remote Repositories (GitHub/GitLab)

Connect your local repository to a cloud server to collaborate with teammates.

Link your local repo to a remote URL:
git remote add origin https://github.com/username/repo.git
Push your local commits to remote main:
git push -u origin main
Pull latest updates from remote server:
git pull origin main
5

Advanced & Undo (Stash & Reset)

Handle messy work-in-progress states and rescue yourself from mistakes.

Temporarily store uncommitted changes:
git stash
Restore stashed changes later:
git stash pop
View commit history log:
git log --oneline --graph
